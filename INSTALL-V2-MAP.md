# V2 Map Explorer — manual GitHub upload

This is a standalone prototype for the India Natural Heritage Explorer. It does not modify your current `index.html` or production website.

## Install as a preview page
1. Upload `v2-preview.html` to the root of your repository: `aniketverse/india-natural-heritage-explorer`
2. Commit the file.
3. Wait for GitHub Pages to finish publishing.
4. Open: `https://aniketverse.github.io/india-natural-heritage-explorer/v2-preview.html`

## Notes
- Uses Leaflet and OpenStreetMap tiles from external CDNs; internet connectivity is required.
- Contains a small illustrative sample dataset only.
- Coordinates, labels and facts are prototype-level and must be checked before authoritative use.
- This is not yet merged into the main homepage.
